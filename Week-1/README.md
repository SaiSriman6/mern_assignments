# JavaScript Practice Programs – README

## Overview

This project contains beginner-friendly JavaScript programs based on:

* Operators
* Control Statements
* Array Operations
* Object Operations

The programs are written using real-world scenarios like:

* Shopping Cart System
* Employee Payroll Processor
* Student Dashboard
* Movie Recommendation System
* Bank Transaction Analyzer
* User Profile Management

These exercises help in understanding core JavaScript concepts using practical examples.

# JavaScript Methods Used

| Method            | Purpose                           |
| ----------------- | --------------------------------- |
| `filter()`        | Returns matching elements         |
| `map()`           | Creates transformed array         |
| `reduce()`        | Reduces array to single value     |
| `find()`          | Returns first matching element    |
| `findIndex()`     | Returns index of matching element |
| `Object.keys()`   | Returns object keys               |
| `Object.values()` | Returns object values             |
| `Object.freeze()` | Prevents object modification      |
